# Isaac ROS2 Panda Tutorials

A collection of ROS2 nodes and notes developed while working through Isaac Sim tutorials for the Franka Panda arm, extended with custom control and motion planning implementations.

## Tutorials Covered

- **ROS2 Joint Control: Extension Python Scripting** — controlling the Panda arm in Isaac Sim using ROS2 and the Isaac Sim Python scripting extension
- **MoveIt 2** — motion planning integration with the Panda arm using the MoveIt 2 framework

## Contents

- `notes/` — markdown notes documenting setup, workflows, and key concepts from the tutorials
- `panda_controllers/` — ROS2 nodes for controlling the Panda arm in Isaac Sim

## Control Development

This repo tracks the progressive development of a controller for the Panda arm in joint and task space, starting from basic position control and extending toward more sophisticated control and motion planning strategies.

## Dependencies

- ROS2
- Isaac Sim
- MoveIt 2

## Notes

This repo is a work in progress and will be updated as development continues.
